3
Import tab → decrypt AAPS export AAPS → ☰ → Maintenance → Export settings. Drop the JSON file here, enter your master password. Active feature gates are auto-detected from your settings.

Gate-aware filtering
Recommendations and AI analysis only show parameters for features that are actually enabled in your settings. Import your AAPS export to activate gate detection.
● ActiveGate = true in your settings → parameters shown
● DisabledGate = false → parameters filtered from all recommendations
⚠ OrphanedDefined in UI but not read by DetermineBasalAIMI2.kt → excluded from analysis
Key gates: T3c adaptive basal · PKPD · Autodrive · NGR · WCycle
Getting the most from AI analysis
✍️
Use the observations field. Describe patterns you've noticed in plain language — "post-meal hypos", "overnight highs", "correction too aggressive". The AI will verify or refute against your CGM data and identify the most likely parameter cause.
🔀
Run a Diff first. Export → import before and after a parameter change. The Diff tab shows exactly which parameters changed and the resulting TIR/CV delta. Paste the diff period into the AI tab for a before/after comparison.
📍
Every recommendation shows its location. Parameter keys in AI output are automatically annotated with their settings path (e.g. 📍 AIMI → T3c & adaptive basal · Requires: T3C Adaptive Basal = ON).
⚠️
Known issue: LastLegacyPrebolusTime. If your AAPS settings contain a timestamp from 2020+, the prebolus delivery detection is permanently stuck. The AI is aware of this bug and will flag it if relevant to your analysis.
