AutoISF Plugin Algorithm Context
========================================

## AutoISF Weights (gate: openapsama_use_autoisf_weights)
Core AutoISF weight system. Six weights control how different signals contribute to ISF adjustment: bgAccel (rising BG), bgBrake (falling BG), lowBg (hypo risk), highBg (hyper), pp (post-prandial), dura (duration). Weights are clamped by ApsAutoIsfMin/ApsAutoIsfMax and bounded by IobThPercent (IOB threshold % of basal).
Key params: autoISF_max, autoISF_min, dura_ISF_weight, iob_threshold_percent, pp_ISF_weight

## SMB Delivery Ratio (gate: openapsama_use_smb)
Dynamic SMB delivery ratio that scales SMB size based on BG position. Ratio/slope with min/max bounds, BG range definition, and max range extension. SmbOnEvenTarget allows delivery even when BG equals target (no delta signal).
Key params: openapsama_smb_delivery_ratio, openapsama_smb_delivery_ratio_bg_range, openapsama_smb_delivery_ratio_max, openapsama_smb_delivery_ratio_min, openapsama_smb_max_range_extension

## Temp Target Interaction (gate: None)
How AutoISF interacts with temp targets. HighTtRaisesSens: high temp target → raise sensitivity (less insulin). LowTtLowersSens: low temp target → lower sensitivity (more insulin). HalfBasalExerciseTarget defines the BG for half-basal during exercise.
Key params: half_basal_exercise_target

## Shared AAPS Settings (gate: None)
Standard OpenAPS settings that AutoISF also reads: max basal, max IOB, SMB gates, autosens, sensitivity/target interactions.
Key params: Enable alternative activation of SMB always, always_use_shortavg, autosens_adjust_targets, autosens_max, autosens_min, bgAccel_ISF_weight, bgBrake_ISF_weight, carbsReqThreshold, enableSMB_after_carbs, enableSMB_always


## Parameter Details

### Enable alternative activation of SMB always (Boolean, default=None)
  Enables/disables Enable alternative activation of SMB always. Gate flag for AutoISF.
  High: Feature is ON — associated functionality runs | Low: Feature is OFF — associated functionality is disabled | Impact: medium

### always_use_shortavg (Boolean, default=None)
  When ON: uses short delta (5min) instead of medium delta (15min) for all calculations.
  High: Feature is ON — associated functionality runs | Low: Feature is OFF — associated functionality is disabled | Impact: medium

### autoISF_max (Double, default=1.0)
  Maximum ISF multiplier (1.0-3.0). Upper bound for AutoISF adjustments. Higher = allows stronger ISF increase (less insulin).
  High: Allows stronger ISF increase → less insulin → more conservative | Low: Limits ISF increase → more insulin → more aggressive | Impact: high

### autoISF_min (Double, default=1.0)
  Minimum ISF multiplier (0.3-1.0). Lower bound for AutoISF adjustments. Lower = allows stronger ISF reduction (more insulin).
  High: Allows stronger ISF reduction → more insulin → more aggressive | Low: Limits ISF reduction → less insulin → more conservative | Impact: high

### autosens_max (Double, default=1.2)
